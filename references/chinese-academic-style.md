# 中文学术写作规范与指南

> 本指南基于以下权威标准编写：
> - **GB/T 7714-2015**《信息与文献 参考文献著录规则》（国家标准）
> - **GB/T 6447-1986**《文摘编写规则》（国家标准）
> - 各高校本科毕业论文管理办法（武汉大学、深圳大学等）

---

## 一、论文基本结构

根据国内高校通用规范，毕业论文由以下部分组成：

| 部分 | 内容 | 说明 |
|------|------|------|
| 前置部分 | 封面、诚信声明、目录 | 学校统一提供 |
| 主体部分 | 中英文摘要、正文、参考文献、致谢 | 核心内容 |
| 附录部分 | 推导过程、程序代码、数据表 | 非必需 |

### 正文结构

| 章节 | 内容 | 建议篇幅 |
|------|------|---------|
| 第一章 绪论 | 研究背景、意义、国内外研究现状、研究内容与创新点 | 15-20% |
| 第二章 相关理论与方法 | 理论基础、方法介绍 | 10-15% |
| 第三章 问题描述与模型构建 | 问题定义、假设、数学模型 | 20-25% |
| 第四章 算法设计 | 算法原理、步骤、复杂度分析 | 20-25% |
| 第五章 实验分析 | 算例设计、结果对比、参数分析 | 15-20% |
| 第六章 结论与展望 | 研究结论、不足、未来方向 | 5-10% |

## 二、摘要写作规范

> 依据：GB/T 6447-1986《文摘编写规则》

### 基本要求

| 项目 | 要求 |
|------|------|
| 字数 | 中文 200-400 字，英文对应 |
| 结构 | 目的、方法、结果、结论四要素 |
| 独立性 | 具有独立性和完整性，不加注释和评论 |
| 禁忌 | 不宜使用公式、图表及非公知公用的符号和术语 |

### 摘要五句公式（Sebastian Farquhar）

1. **你做了什么**："本文提出/设计/构建了..."
2. **为什么重要且困难**：问题背景与挑战
3. **你如何做**：含专业关键词的方法描述
4. **你有什么证据**：实验/算例验证
5. **你最突出的数据**：核心量化结果

### 关键词

| 要求 | 说明 |
|------|------|
| 数量 | 3-8 个 |
| 来源 | 从摘要中选取 |
| 类型 | 通用技术词汇，不得自造 |
| 排列 | 按外延层次由高至低 |
| 分隔 | 中文用分号"；"分隔 |

## 三、参考文献规范

> 依据：GB/T 7714-2015《信息与文献 参考文献著录规则》

### 著录体系

国内论文**普遍采用顺序编码制**：

- 正文中按引用先后顺序用方括号标注序号，如 [1]、[2-4]
- 文后参考文献表按序号排列

### 文献类型标识

| 标识 | 文献类型 | 标识 | 文献类型 |
|------|---------|------|---------|
| M | 专著/图书 | J | 期刊文章 |
| C | 会议论文 | D | 学位论文 |
| R | 报告 | S | 标准 |
| N | 报纸文章 | EB/OL | 电子资源 |

### 著录格式

#### 期刊文章

```
[序号] 作者. 题名[J]. 刊名, 年, 卷(期): 起止页码.
```

**示例**：
```
[1] 张三, 李四. 基于 Benders 分解的选址-路径问题研究[J]. 运筹与管理, 2024, 33(5): 1-10.
[2] SMITH J, DOE A. A Benders decomposition approach for facility location[J]. European Journal of Operational Research, 2023, 305(2): 567-580.
```

#### 专著/图书

```
[序号] 作者. 书名[M]. 版本(初版不写). 出版地: 出版者, 出版年: 引用页码.
```

**示例**：
```
[3] 胡运权. 运筹学教程[M]. 5 版. 北京: 清华大学出版社, 2018: 45-60.
[4] DASKIN M S. Network and discrete location: models, algorithms, and applications[M]. 2nd ed. Hoboken: Wiley, 2013.
```

#### 学位论文

```
[序号] 作者. 题名[D]. 保存地: 保存单位, 年份.
```

**示例**：
```
[5] 王五. 随机需求下的设施选址问题研究[D]. 北京: 北京交通大学, 2023.
```

#### 会议论文

```
[序号] 作者. 题名[C]// 会议论文集名. 出版地: 出版者, 年份: 起止页码.
```

#### 电子资源

```
[序号] 作者. 题名[EB/OL]. (更新或修改日期)[引用日期]. 获取和访问路径. DOI.
```

### 著录细则

| 规则 | 说明 |
|------|------|
| 作者人数 | 3 人以内全部列出，超过 3 人加"等"或"et al." |
| 英文作者 | 姓全大写，名缩写为首字母 |
| 中文作者 | 姓全大写，名可缩写 |
| 标点符号 | 著录用半角标点 |
| 页码连接 | 用"--"连接起止页码 |
| 同一作者同年 | 出版年后加 a, b, c 区分 |

### 数量要求

| 类型 | 最低要求 |
|------|---------|
| 参考文献总数 | 一般不少于 10 篇 |
| 学术期刊 | 不少于 5 篇 |
| 外文文献 | 不少于 2 篇 |

## 四、数学公式排版规范

### 公式编号

- 使用"章-序号"格式，如第 3 章第 1 个公式编号为 (3-1)
- 公式应居中排版，编号右对齐

### 公式与文字衔接

公式应作为句子的组成部分，前后应有文字衔接：

```latex
目标函数可表示为：
\begin{equation}
\min Z = \sum_{i \in I} f_i x_i + \sum_{s \in S} p_s Q_s(x)
\label{eq:3-1}
\end{equation}
其中，$f_i$ 为设施 $i$ 的固定建设成本，$x_i$ 为 0-1 决策变量。
```

### 符号使用原则

1. **首次定义**：每个符号在首次出现时必须明确定义
2. **全文一致**：同一符号全文含义一致
3. **符号表**：建议在论文开头或附录提供符号说明表
4. **避免混淆**：不同含义不使用相同符号

### 常用数学环境

```latex
% 定理
\begin{theorem}[定理名称]
定理内容
\end{theorem}

% 定义
\begin{definition}[定义名称]
定义内容
\end{definition}

% 证明
\begin{proof}
证明过程
\end{proof}
```

## 五、图表规范

### 编号规则

- 按章节编号：图 X-X、表 X-X（章-序号）
- 图题在图下方，表题在表上方
- 编号与题名之间空一个汉字符

### 图

```latex
\begin{figure}[htbp]
\centering
\includegraphics[width=0.8\textwidth]{figures/algorithm_flow.pdf}
\caption{算法流程图}
\label{fig:4-1}
\end{figure}
```

### 表（三线表）

```latex
\begin{table}[htbp]
\centering
\caption{实验结果对比}
\label{tab:5-1}
\begin{tabular}{cccc}
\toprule
方法 & 求解时间(s) & Gap(\%) & 迭代次数 \\
\midrule
传统 Benders & 1250.3 & 2.1 & 156 \\
改进 Benders & 389.7 & 0.8 & 42 \\
\bottomrule
\end{tabular}
\end{table}
```

### 三线表规范

- 使用 `\toprule`、`\midrule`、`\bottomrule`（需 `booktabs` 宏包）
- 表题在表上方居中
- 表注在表下方（如有）
- 表中数字不重复标注单位，统一在表头标明

### 图表可访问性

- 使用色盲安全调色板（Okabe-Ito 或 Paul Tol）
- 避免红绿组合
- 除颜色外使用不同线型（实线、虚线、点线）
- 验证图表在灰度下有效

## 六、算法伪代码规范

```latex
\begin{algorithm}
\caption{Benders 分解算法}
\label{alg:4-1}
\begin{algorithmic}[1]
\REQUIRE 初始解 $x^0$，收敛阈值 $\epsilon$
\ENSURE 最优解 $x^*$
\STATE $k \gets 0$，$UB \gets +\infty$，$LB \gets -\infty$
\WHILE{$(UB - LB) / |UB| > \epsilon$}
    \STATE 求解主问题，得到 $x^k$
    \STATE 求解子问题，得到对偶信息
    \IF{子问题可行}
        \STATE 生成最优割平面
    \ELSE
        \STATE 生成可行割平面
    \ENDIF
    \STATE 更新上下界
    \STATE $k \gets k + 1$
\ENDWHILE
\RETURN $x^*$
\end{algorithmic}
\end{algorithm}
```

## 七、中文学术用语规范

### 与英文论文的差异

| 维度 | 英文论文 | 中文论文 |
|------|---------|---------|
| 句式结构 | 主谓宾清晰，短句为主 | 允许较长复合句，但应避免过度嵌套 |
| 被动语态 | 常用（尤其方法部分） | 较少使用，偏好"本文"、"本研究"作主语 |
| 第一人称 | "We" 常见 | "本文"、"本研究"更正式，避免过多"我们" |
| 段落长度 | 较短（3-5句） | 可稍长，但仍应保持一个段落一个观点 |

### 推荐用语

| 场景 | 推荐用语 |
|------|---------|
| 引出贡献 | "本文提出..."、"本研究设计了..." |
| 描述方法 | "采用...方法"、"基于...框架" |
| 陈述结果 | "实验结果表明..."、"数据证实..." |
| 对比分析 | "相较于...，本文方法..." |
| 总结结论 | "综上所述..."、"研究表明..." |

### 避免用语

| 类型 | 避免 | 替代 |
|------|------|------|
| 口语化 | "搞定了"、"弄出来了" | "实现了"、"构建了" |
| 过度谦虚 | "初步尝试"、"粗糙的方法" | "提出的方法"、"设计的算法" |
| 空洞修饰 | "非常好的效果" | "求解时间缩短 32%" |
| 主观判断 | "显然"、"毫无疑问" | "实验结果表明" |

## 八、排版通用规范

> 以下为国内高校通用规范，**具体以学校模板为准**

| 项目 | 常见要求 |
|------|---------|
| 纸张 | A4 |
| 页边距 | 上下 3.0cm，左右 2.6cm |
| 正文字体 | 中文宋体，英文 Times New Roman |
| 正文字号 | 小四号（约 12pt） |
| 行距 | 1.5 倍行距或固定值 20pt |
| 段落 | 首行缩进 2 字符 |
| 标题层次 | 1 → 1.1 → 1.1.1 |
| 页码 | 正文从第一章开始用阿拉伯数字 |

## 九、常见错误与解决方案

| 错误 | 解决方案 |
|------|---------|
| 摘要空洞开头 | 以具体贡献开头，不用"随着...的发展" |
| 术语不一致 | 每个概念选择一个术语并坚持 |
| 逐篇罗列文献 | 按主题组织文献综述 |
| 模糊表达 | 使用具体数据替代"很好"、"显著" |
| 图表无来源 | 非自制图表需注明出处 |
| 公式无编号 | 正文引用的公式必须编号 |
| 参考文献未引用 | 文后参考文献必须在正文中有引用标注 |
