# 论文撰写检查清单

## 叙事检查

- [ ] 能用一句话清晰陈述论文的核心贡献
- [ ] "是什么"（1-3 个具体创新点）在引言中明确
- [ ] "为什么"（实验证据支持）在实验章节体现
- [ ] "有何意义"（实际价值）在引言和结论中表达
- [ ] 每个实验/分析都支持一个具体声明

## 结构检查

- [ ] 摘要遵循 5 句公式（做了什么、为什么重要、如何做、证据、突出结果）
- [ ] 摘要无空洞开头（如"随着经济发展..."）
- [ ] 引言长度适中（通常 1-1.5 页）
- [ ] 引言包含 2-4 条贡献列表
- [ ] 模型/方法章节在合理位置开始（第 2-3 页）
- [ ] 文献综述按主题组织，非逐篇罗列
- [ ] 包含结论与展望章节

## 写作质量检查

- [ ] 全文术语一致（同一概念使用同一术语）
- [ ] 无不必要的模糊表达（删除"非常"、"极其"等）
- [ ] 使用主动语态（"本文提出"而非"被提出"）
- [ ] 段落首句明确陈述观点
- [ ] 图表编号正确（图 X-X、表 X-X）
- [ ] 公式编号正确（X-X 格式）
- [ ] 所有图表有自包含图注

## 参考文献检查

- [ ] 所有引用已通过搜索验证
- [ ] 无编造或无法验证的文献
- [ ] 待验证引用已明确标记
- [ ] 参考文献格式符合 GB/T 7714
- [ ] .bib 文件完整且格式正确

## LaTeX 技术检查

- [ ] LaTeX 编译无错误
- [ ] 交叉引用正确（图表、公式、章节）
- [ ] 参考文献列表正确生成
- [ ] 目录自动生成且页码正确
- [ ] 图表使用矢量格式（PDF/EPS）
- [ ] 中文字体正确显示

## 最终确认

- [ ] 论文题目准确反映内容
- [ ] 作者信息、学院、专业等封面信息正确
- [ ] 中英文摘要内容对应
- [ ] 关键词 3-5 个，分号分隔
- [ ] 致谢部分完整
- [ ] 附录材料完整（如有）
